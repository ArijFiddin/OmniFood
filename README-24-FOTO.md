# OmniFood — 24 Foto Final

Paket ini berisi 24 file foto individual hasil pemotongan tile foto dari satu lembar visual yang dibuat khusus untuk OmniFood.
Setiap file sudah dipisahkan, diberi nama sesuai kebutuhan project, dan disimpan sebagai WebP.

## Isi paket

### Customer avatars — 6 foto
Lokasi: `omnifood/assets/images/customers/`
- customer-01.webp sampai customer-06.webp
- Untuk enam avatar pada area pelanggan / delivered meals.

### Meal cards — 2 foto
Lokasi: `omnifood/assets/images/meals/`
- japanese-gyozas.webp — kartu menu Japanese Gyozas.
- avocado-salad.webp — kartu menu Avocado Salad.

### Testimonials — 4 foto
Lokasi: `omnifood/assets/images/testimonials/`
- dave-bryson.webp
- ben-hodley.webp
- steve-miller.webp
- hannah-smith.webp
- Untuk foto profil pada empat kartu testimonial sesuai nama yang digunakan project.

### Gallery — 12 foto
Lokasi: `omnifood/assets/images/gallery/`
- gallery-01.webp sampai gallery-12.webp
- Untuk grid gallery makanan.

## Cara memasang
Ekstrak isi ZIP ke folder project sehingga folder `omnifood/assets/images/` bergabung dengan folder aset project yang sudah ada.
Jika diminta konfirmasi overwrite, jangan menimpa aset logo, hero, app, atau CTA yang sudah dibuat sebelumnya; folder dalam paket ini hanya customers, meals, testimonials, dan gallery.

## Catatan
Foto merupakan aset visual AI untuk mockup/demo website. Nama pada file testimonial adalah label penempatan pada template, bukan klaim bahwa orang pada foto adalah pelanggan nyata atau orang bernama tersebut.
